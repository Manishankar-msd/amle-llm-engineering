# Data

Everything in this folder is **fictional**. Tretwerk does not exist; its handbook and its customers' emails were written for these notebooks, so that a language model cannot know them from its training and has to use the documents.

| File / Folder | Contents | Used in |
|---|---|---|
| `handbook/` | Tretwerk's support handbook: 20 Markdown pages, about 2,100 words, one topic per page (plans, cancelling, pausing, theft, repairs, error codes and more) | notebooks 02 and 03 |
| `emails.csv` | 14 customer emails, each with the category a support agent gave it (`billing`, `repair`, `theft`, `contract`, `delivery` or `other`) | notebook 01 |

Some pages are deliberately close to each other, such as cancelling and pausing, or theft and accident damage, so that retrieval has hard cases.
