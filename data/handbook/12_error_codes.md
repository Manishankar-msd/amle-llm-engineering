# Display Error Codes

The display shows an error code when the bike detects a problem. Agents ask the customer for the code before booking a repair.

| Code | Meaning | What the customer should do |
|---|---|---|
| E-03 | Battery not detected | Remove the battery and insert it again until it clicks |
| E-07 | Motor overheated | Stop, wait 15 minutes, then continue at a lower assistance level |
| E-12 | Speed sensor error | Check that the magnet on the rear wheel is in place, then book a repair |
| E-21 | Battery temperature too low | Bring the battery indoors and let it warm up |
| E-30 | Controller fault | Do not ride the bike; book a repair |

If a code appears three times in one week, the agent books a repair even if the bike works again.
